# MEDICAL-WEB-V1 🏥

A multi-page hospital website built with HTML, showcasing a full patient/doctor/reception workflow — from browsing services to booking appointments and managing dashboards.

## 📄 Pages

| Page | File | Description |
|---|---|---|
| Home | `page1_home.html` | Landing page for the hospital website |
| Services | `page2_services.html` | Overview of medical services offered |
| Doctors | `page3_doctors.html` | List/profiles of doctors |
| About Us | `page4_aboutus.html` | Hospital background and mission |
| Reviews | `page5_reviews.html` | Patient testimonials and reviews |
| Appointment | `page6_appointment.html` | Appointment booking form |
| Doctor Portal | `page7_doctor_portal.html` | Portal for doctors to manage their info |
| Doctor Dashboard | `Page8_doctor_dashboard.html` | Dashboard view for doctors |
| Reports | `page9_reports.html` | Patient/medical reports view |
| Patient Portal | `page10_patient_portal.html` | Portal for patients to manage records/appointments |
| Reception / Admin Panel | `Reception_admin_panel.html` | Admin panel for reception staff |
| Login | `login.html` | Login page for users (patients/doctors/admin) |

## 🚀 Getting Started

This is a static website — no build tools or server-side setup required.

1. Clone the repository
   ```bash
   git clone https://github.com/Anmolspaxe/MEDICAL-WEB-V1.git
   cd MEDICAL-WEB-V1
   ```
2. Open any HTML file directly in your browser, starting with `page1_home.html` or `login.html`.

   Or serve it locally for a smoother experience (recommended if you add JS that fetches local files):
   ```bash
   npx serve .
   # or
   python -m http.server 8000
   ```
3. Navigate the site using the links between pages.
